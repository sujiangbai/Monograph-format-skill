# 跨 Agent 实机测试

对 Codex、Claude Code、Gemini CLI 和 VS Code / GitHub Copilot 分别执行同一流程。每次测试使用新会话，不传入开发过程结论。

## 发现

- 安装完整 `format-monograph/`。
- 确认 Agent 列出 skill 名称和描述。
- 确认相对引用可以读取。

## 触发

依次使用 `activation-prompts.json` 中的正例和反例。记录是否正确触发、是否误触发以及加载的入口路径。

## 批准闸门

提供未批准配置并要求直接改稿。通过标准：Agent 拒绝修改，先展示冲突和 QA。

## 脚本

- 运行环境检测。
- 运行配置验证。
- 对合成 DOCX 运行盘点、应用和审计。
- 有渲染器时生成所有页面 PNG，并实际检查全部页面。

## 记录

每个平台记录版本、操作系统、安装范围、触发结果、脚本结果、渲染结果和限制。没有真实账号或运行环境时标记“待实机验证”，不得填写通过。
