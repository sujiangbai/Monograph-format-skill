# GB/T 15834—2011 规则摘要

## 来源

- 标准名称：《标点符号用法》
- 标准编号：GB/T 15834—2011
- 用户提供文件：不提交仓库
- 本摘要用途：建立专著格式和审校规则，不替代标准原文
- 自动修改边界：不得增删、替换或重排作者输入的标点字符

## 可进入格式验收的规则

| 规则主题 | 条款定位 | V1 处理 |
| --- | --- | --- |
| 句号、逗号、顿号、分号、冒号、问号和叹号不得置于行首 | 5.1.1—5.1.2 | 渲染后逐页检查；当前为人工复核 |
| 前引号、前括号、前书名号不得置于行末；对应后半部分不得置于行首 | 5.1.3 | 渲染后逐页检查；当前为人工复核 |
| 破折号和省略号按两个汉字位置处理，且不得从中间断到两行 | 5.1.4—5.1.5 | 渲染后逐页检查；当前为人工复核 |
| 连接号、间隔号和分隔号的占位、居中与行首行末限制 | 5.1.6—5.1.9 | 渲染后逐页检查；当前为人工复核 |
| 全角标点位于行末时允许压缩其视觉占位；必要时可适当压缩标点空间改善版面 | 5.1.10—5.1.11 | 只作为排版策略候选，需出版社规则确认 |
| 竖排文稿中的标点位置、方向、引号括号形式及专名号位置 | 5.2 | 仅在输入文档包含竖排内容时复核 |
| 章节、条款和列表序次语的层级及标点形式 | B.3 | 可用于批准的标题编号派生字段；现阶段人工复核 |
| 文章标题末尾通常不使用标点，问号、叹号或省略号可按语义保留 | B.4 | 只报告，不删除标题中的现有字符 |

## 只允许审校提示的规则

以下内容会改变作者输入的字符或语义，V1 不得自动修改：

- 各类标点的选择、增删、替换和连用方式。
- 引号、括号和书名号内外标点的调整。
- 标题末尾标点的删除。
- 日期连接符、间隔号、序次语标点和书名号形式的字符替换。
- 附录 A 和附录 B 中针对误用示例的文字校订。

报告应给出标准编号、条款定位、问题摘要和建议，不复制大段标准原文。

## 实施限制

DOCX 的禁则、字符级占位和标点压缩通常依赖字体、语言设置、兼容模式及实际排版引擎。结构检查通过不代表视觉合规；完整模式必须渲染全部页面后检查。
