# GB/T 15835—2011 规则摘要

## 来源

- 标准名称：《出版物上数字用法》
- 标准编号：GB/T 15835—2011
- 用户提供文件：不提交仓库
- 本摘要用途：建立专著格式和审校规则，不替代标准原文
- 自动修改边界：不得改变作者输入的数字、单位、日期、时间或编号字符

## 可进入格式验收的规则

| 规则主题 | 条款定位 | V1 处理 |
| --- | --- | --- |
| 出版物中的阿拉伯数字通常使用正体，按半个汉字位置排印 | 5.1.7.1 | 字体和字符宽度需结合出版社指定字体确认；当前人工复核 |
| 一个完整数值应保持在同一行，避免从中间断开 | 5.1.7.2 | 渲染后逐页检查；当前人工复核 |
| 竖排文本中的阿拉伯数字按规定方向旋转，并保持词语单位方向一致 | 5.1.7.3 | 仅在输入文档包含竖排内容时复核 |
| 同类或同级数字形式应保持一致 | 4.3 | 可做一致性审计，不自动转换 |
| 同级目录和标题编号形式应一致 | 4.3 | 可用于批准的标题编号派生字段；现阶段人工复核 |

## 只允许审校提示的规则

以下内容会改变作者输入字符，V1 不得自动修改：

- 阿拉伯数字与汉字数字的选择和互换。
- 多位数分节、小数点、数值范围及单位写法。
- 年月日、时分秒、年份简写和专名中的数字写法。
- 概数、大写汉字数字、“零”与“○”的选择。
- 阿拉伯数字与汉字数字混合形式的修改。
- 为满足“同类别同形式”原则而改写正文数字。

报告应定位到段落或表格单元格，说明标准条款和建议形式；不得直接替换正文。

## 实施限制

正体、半字身和不拆行效果取决于字体度量、Word 兼容设置及渲染器。缺少出版社指定字体时必须停止并通过 QA 确认，不能用相近字体代替。
