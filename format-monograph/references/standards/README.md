# 标准资料摘要

本目录保存可公开的规则摘要，不保存用户提供的原始标准文件、扫描件或大段原文。

## 使用方式

1. 读取对应标准摘要和条款定位。
2. 将规则加入任务专用的 `format-profile.json` 草案。
3. 将影响字符内容的规则标记为 `manual_review`。
4. 将当前脚本不能可靠执行的排版规则也标记为 `manual_review`。
5. 用户批准具体规则前，不修改 DOCX。
6. 出版社已批准的具体要求在来源排序中优先，基础标准在出版社未规定时作为默认规则。\n7. 双方对同一对象和属性发生冲突时，不得静默选择；建立开放冲突项并等待用户决定采用哪一项。
