# Sample references

This directory stores paraphrased layout observations derived from sample books.

## Safety and authority

- Do not commit source books, page images, OCR text, or local file paths.
- Treat a sample book as corroborating layout evidence, not as a publisher requirement.
- Record scan-dependent geometry, inferred fonts, and measured spacing as candidates only.
- The current caller's explicit formatting requirements and QA decisions have the highest formatting authority for that task.
- If samples or lower-priority standards differ, report the difference; do not silently combine or override rules.
- A sample-derived profile remains `draft` until the caller approves the applicable rules and supplies enough evidence for exact values.
- Sample scans never justify converting equations to images. Formulas must remain editable.
