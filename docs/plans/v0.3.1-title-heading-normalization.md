# format-monograph V0.3.1：书名页与标题缩进确定性修复

## 背景与结论

跨 Agent 单章试排暴露出两个可复现的可靠性缺口：

1. 标题页虽然设置了 Word 分节垂直居中，但自动插入的空分节段也参与页面内容高度计算，导致书名文字块视觉上偏离页面正中心。
2. 标题规则与测试只充分约束了首行缩进，没有同时约束左缩进、右缩进、悬挂缩进、字符缩进和段落级旧编号覆盖，导致二至四级标题可能继承原稿的不同缩进。

当前唯一公开预发布版为 `v0.2.6-rc.1`；V0.3.0 已进入 `main`，但尚未发布。升级到 V0.3.0 本身不能完全修复上述两个实现缺口。

本版本只修复格式确定性和验收门禁，不改变正文、标题文字、标题层级、编号内容、图表位置或其他已批准规则。

## 书名页规则

- 书名文字块必须同时水平居中和垂直居中。
- 垂直居中以书名段落自身为计算主体；自动生成的分节边界、空段和分页辅助对象不得改变书名文字块的中心位置。
- 书名段落显式清除首行、悬挂、左、右及字符缩进，并清除段落级列表或编号覆盖。
- 书名保持黑体、加粗、二号候选格式及已批准的最小行距规则；多行书名不得截字。
- 书名页不显示页码，也不计入目录页码。
- 书名与目录之间如果存在非空正文、图片、表格或其他作者内容，停止标题页重构并生成阻塞 QA，不得移动或删除这些内容。
- 只允许删除或折叠 skill 自动生成且经指纹确认的无内容分页辅助段；不得把作者空段默认为可删除内容。

## 章内标题规则

- 章题继续居中；二至四级标题统一左对齐并从版心左边界起排。
- Heading 1–4 均显式设置：
  - 首行缩进 0；
  - 左缩进 0；
  - 右缩进 0；
  - 悬挂缩进 0；
  - 字符缩进 0。
- 在用户已批准重建标题编号时，清除标题段落原有的直接 `numPr`，只使用与 Heading 1–4 样式关联的批准多级列表。
- 未批准重建编号时，不得静默删除可能承载有效编号的 `numPr`；若旧编号造成缩进冲突，冻结相关标题并提出 QA。
- 多级列表的每一级同步设置零左缩进、零悬挂缩进，并使用空格而不是制表位分隔编号与标题。
- 编号和标题文字必须使用同一字号、字重和对应的中西文字体规则。

## 实现与审计

- 调整标题页分节构造，使自动分页辅助段不再影响书名文字块的垂直中心。
- 新增结构段落规范化函数，针对书名与批准标题清除受控的残留缩进和列表覆盖。
- 新建理工科教材 V0.3.1 候选配置，不覆盖现有 V0.2、V0.2.5 配置快照。
- 扩展审计，至少报告：
  - 书名水平与垂直居中；
  - 标题页辅助段是否影响布局；
  - Heading 1–4 的有效首行、左、右和悬挂缩进；
  - 标题是否存在未经批准的直接编号覆盖；
  - 标题编号与文字的字体、字号和字重一致性。
- `run_monograph.py` 在上述关键审计失败时不得进入 `candidate_ready` 或 `final_ready`。
- 跨 Agent 清单明确要求调用脚本并保留运行状态证据；仅凭 Agent 文字判断或 Word 可打开不得声明完成。

## 测试与验收

- 合成标题页包含：两行长书名、直接缩进、列表覆盖、前后空段及自动分节辅助段；渲染后书名文字块中心与可用页面中心的偏差必须在允许的排版误差内。
- 合成 Heading 1–4 包含不同左缩进、悬挂缩进、字符缩进、制表位和直接 `numPr`；批准编号重建后有效缩进必须全部归零。
- 测试未批准编号重建时保留有效编号并产生冲突 QA，不能误删编号。
- 在 Word 和 LibreOffice 中检查长书名不截字、目录另起一页及标题起排位置一致。
- 保持正文指纹、公式、OLE、媒体和嵌入对象不变。
- 在首批跨 Agent 环境使用同一合成 DOCX 前向测试；无法实机验证的平台继续标记待验证。
- 正式书稿、截图文字、试排文件和本地路径不得进入仓库、CI 日志或发布附件。

## 治理与发布

1. 从最新 `main` 创建 `plan/v0.3.1-title-heading-normalization`，新增本方案并更新索引。
2. 方案 PR 经用户明确批准并合并后，从最新 `main` 创建 `skill/v0.3.1-title-heading-normalization`。
3. 实现 PR 完成合成测试、跨平台 CI 和私密单章复测后，单独请求合并批准。
4. 合并后再决定是否发布 `v0.3.1-rc.1`；不得移动或覆盖 `v0.2.6-rc.1` 标签。

## 已确定默认

- “页面正中间”指书名文字块本身相对于可用页面区域的水平与垂直中心，不包含分节辅助空段。
- “标题无缩进”指二至四级标题的编号起点位于版心左边界，所有受控缩进值均为 0。
- 书名、标题、图表及其他内容在文中的逻辑顺序和锚点保持不变。
- 当前调用者的明确格式要求仍是任务级最高格式依据，但不能突破内容和对象保护边界。
