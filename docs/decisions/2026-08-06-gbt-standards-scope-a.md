# GB/T 标准纳入范围决策 A

- 日期：2026-08-06
- 状态：已由用户确认
- 关联资料：GB/T 15834—2011、GB/T 15835—2011

## 决策

V1 继续遵守“只修改格式和批准的派生字段，不修改作者正文”的边界。

1. 标点位置、占位、禁则、数字字形方向、数字不拆行和序次层级等排版要求，可进入格式规则或视觉验收规则。
2. 标点选用、标点增删、汉字数字与阿拉伯数字转换、日期时间改写、数值表达改写等会改变字符内容的要求，只生成审校警告。
3. 即使审校结论置信度高，也不得自动修改正文；需要用户在 Skill 外完成文字修订，或通过后续新方案明确扩大范围。
4. 两份原始 PDF 不进入公开仓库。仓库只保存标准编号、条款定位和简要释义。
5. 本决策不改变既有来源优先级。两份标准作为基础规范，遇到出版社书面要求、模板或已批准专著规则时，按格式配置中声明的优先级处理。

## 变更规则

后续若允许自动修改标点或数字写法，必须新建方案版本、分支和 PR；不得覆盖本决策记录。
