# 出版社要求与基础标准冲突决策

- 日期：2026-08-06
- 状态：已由用户确认
- 适用范围：GB/T 15834—2011、GB/T 15835—2011 及后续基础标准摘要

## 决策

1. 出版社已批准的具体要求在来源排序中优先于两份 GB/T 基础标准。
2. 两份 GB/T 标准在出版社没有明确要求时作为默认基础规则。
3. 当出版社规则与基础标准对同一对象、同一属性给出不一致要求时，Agent 不得仅依据优先级静默选择。
4. Agent 必须建立开放冲突项，说明双方来源、条款定位、差异及影响，并通过 QA 等待用户决定采用哪一项。
5. 用户作出决定前，相关规则不得批准，也不得修改 DOCX；不受冲突影响的规则可以继续整理，但仍受整体批准闸门约束。
6. 冲突解决结果应记录在任务专用格式配置中，不回写或覆盖本决策。

## 后续变更

如需对某类冲突设定无需询问的固定裁决规则，必须通过新的方案或决策文件、独立分支和 PR 处理。
